# JPDFs — product overview

JPDFs is a Windows desktop application for working with PDF documents. It brings reading, annotation, page management, conversion and document protection into one workspace.

This page introduces the main areas of the application. Exact options can vary with the document, installed components and application version.

## Read and navigate

- Open multiple documents in tabs or split panes.
- Search for text and navigate with bookmarks.
- Inspect document comments, attachments, layers and digital signatures.
- Dock the sidebar on different sides of the workspace.

## Annotate and edit

- Add text, freehand drawings, highlights, shapes, stamps and images.
- Insert measurements and reusable signatures.
- Edit supported PDF text line by line or by paragraph.
- Use Find and Replace for matching text across a document.

Text editing depends on the structure and fonts used by the source PDF. Scanned documents require OCR before their recognized text can be edited.

## Manage pages and documents

- Merge and split PDF files.
- Extract, reorder, rotate, crop and resize pages.
- Straighten supported page content.
- Compare two documents side by side and review detected differences.

## OCR and conversion

JPDFs can run OCR on scanned pages, let users review recognized text and save searchable PDF copies.

Supported conversion workflows include exporting PDF content to Word, Excel, PowerPoint, HTML, Markdown, plain text, JSON and page images. Supported Word and Excel documents can also be converted to PDF. Converted Office files may have layout differences and should be reviewed.

## Forms, redaction and protection

- Create, fill and flatten PDF forms.
- Recognize form fields and exchange form data or comments through FDF and XFDF.
- Redact content by area, text search or sensitive-data pattern.
- Protect document copies with passwords or certificate recipients.
- Sign PDFs and inspect signature integrity, certificate chains, timestamps and later changes.

A signature report may distinguish a failed validation from evidence that is unavailable or has not been checked. Review the report before relying on a signature.

## Automation and customization

- Use guided tasks, macros and watched folders for repeated operations.
- Work with data merge and command-line workflows.
- Choose from 13 themes and 20 interface languages.
- Customize keyboard shortcuts and interface scaling.
